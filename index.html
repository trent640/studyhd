CHALLENGE 01 · OOP

Build a simple class system

Create a Course class with a name and a list of lessons. Add a method that returns the lesson titles in order.

// Pseudocode: class Course { constructor(name) { this.name = name; this.lessons = []; } addLesson(title) { this.lessons.push(title); } lessonOrder() { return this.lessons.map(l => l.title); } } // Test: add two lessons, check the order matches.

What Irish employers want

Common requirements across 10 software internship roles in Ireland, 2025–2026
MUST-HAVE

Core technical requirements

Object-oriented design & software design principles. Covered in oop and software-engineering modules.
Data structures & algorithms: arrays, lists, trees, hash maps, sorting, searching. Covered in algorithms and databases modules.
At least one modern language: Java, Python, JavaScript/TypeScript, C++. Covered in cloud-frameworks (Java), web-patterns (JavaScript), data-analysis (Python-style SQL).
SQL and relational databases: queries, joins, indexes, normalization. Covered in databases and db-management modules.
Version control: Git and GitHub. Practice creating repos, commits, and pull requests.
Testing: unit tests, integration tests, TDD basics. Covered in software-engineering and testing modules.
NICE-TO-HAVE

Preferred qualifications

Modern web technologies: HTML/CSS, JavaScript, React or similar. Covered in web-patterns module.
REST APIs and web service integration. Covered in web-patterns and cloud-frameworks modules.
AI-assisted development and model APIs. Covered in cloud-frameworks module.
CI/CD basics and automated testing. Covered in testing and software-engineering modules.
Data manipulation and analysis. Covered in data-analysis module.

How to use this map

Pick a module, build a small project around it, and put it in your portfolio. Ireland employers want to see you built things, not just studied them.

Your 12-week internship prep plan

Week 1–2: Finish oop and software-engineering modules. Build a small project: a class-based app with tests.
Week 3–4: Finish algorithms and databases modules. Build a database-backed app. Add a REST API.
Week 5–6: Finish web-patterns and cloud-frameworks modules. Build a full web app with React + Spring Boot.
Week 7–8: Finish security and testing modules. Write unit tests and integration tests for your project.
Week 9–10: Build your portfolio: 3 projects with README files, screenshots, and a GitHub repo.
Week 11–12: Interview practice: use the interview view to practice explaining your code. Apply to 10 roles.
